# Client Mode — Complete Engineering Handoff 1.3

Start with [START_HERE.md](START_HERE.md) and [BUILD_PROMPT.md](BUILD_PROMPT.md).

This consolidated package contains 80 requirements, eight workstreams and 33 implementation tasks, the machine contracts/API/storage design, executable reference/schema tests and an evidence-based shipping plan. It is **not an installed Client Mode application**.

The AI engineers work across client stacks. One lead owns research, product, UI/UX, development and QA without requiring the client to manage workers or write documents. The toolkit may use TypeScript.

New in v1.3: first-party research on mature technology-company practices; document-only analysis/review/writing and editable exports; PDF/DOCX/XLSX/CSV/TSV/PPTX/image processing requirements; exact source references and coverage; real numerical verification; technical writer/editor roles; risk-based discovery and on-demand support; integrated document/software qualification and release.
