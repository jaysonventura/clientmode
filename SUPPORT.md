# Support and incidents

- Owner: the engineering team that installed this build
- Response target: next working day for questions; same working day for a failed release or a lost run
- Escalation: the release owner named in `qa/product/STATUS.md`

## What support covers

Installation, upgrade and uninstall of this build; a run that is stuck, blocked or lost; a
verification result you cannot interpret; a deployment that did not reconcile.

## What support does not cover

Provider account problems, metered API billing, and any environment this build reports as a
capability gap. Those are reported back to you with the gap named, not worked around.

## Reporting an incident

The operational runbooks are in [docs/runbooks/](docs/runbooks/README.md). Attach the run id
and the evidence directory under `qa/product/`; both are on the run's page in the console.
