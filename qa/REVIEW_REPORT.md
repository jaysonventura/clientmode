## Verification history

New document regression tests were written and executed before adding the new shapes. Initial failures included missing definitions/fixtures; these establish a missing contract, not a parser flaw. Additional negative tests exposed unsupported generated scope, one-sided conflicts and permissive API input/revision rules; those were corrected and rerun. A test-fixture SQL placeholder count was corrected during preparation. Retained red/green logs are under `qa/review-evidence-v1.3/` (repository-root path). Final authoritative reference results are under `qa/current/`.

Every normative requirement maps to tasks and explicit product assertions. Plan test dictionaries match scenario contracts and dependency IDs are acyclic. These structural facts are useful handover checks, but a task executor returning the expected dictionary would still fail the real Definition of Done.
