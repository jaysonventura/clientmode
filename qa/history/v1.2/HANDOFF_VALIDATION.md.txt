## Reproduce

From the extracted root:

```bash
python3 scripts/validate_all.py
```

This command requires Node.js, Python 3.9+, the jsonschema package and tsc. It does not install dependencies, call an AI provider or touch a client project. Missing required tools/checks return nonzero. Successful structural validation does not erase separately listed unperformed checks.

The actual commands, timestamps, exit codes and logs are in [current validation](current/validation.json). The combined runner retains logs for all checks even when one fails. It rewrites `qa/current/`; verify distributed archive checksums **before** rerunning it. The package SHA256SUMS identifies the distributed snapshot, not later locally regenerated logs.

The baseline and failure-first regression work is described in [the review report](REVIEW_REPORT.md). Historical input records remain under `qa/history/v1.1/` and are not the current results.
